## Decisions already closed — do not reopen

- **TTS is local Chatterbox Turbo.** ElevenLabs and Sarvam ruled out after a real listen.
- **The LLM is Claude in-session, via the skill.** Not the Messages API, not a `claude -p` subprocess.
- **Alignment is torchaudio, not WhisperX.** The text is known exactly, so transcription was never needed.
- **Cross-scene voice consistency: closed by decision.** Aman judged the six-scene clip consistent and declined a 34-scene test. Do not re-raise. If drift appears later, try pinning the seed per scene and re-conditioning on the reference more often.
- **Remotion, licence deferred.** Free below 4 people, headcount-based, internal use counts — a work laptop triggers it. `render/CONTRACT.md` keeps a Motion Canvas swap cheap.
- **1080p30 stands.** Rendering is faster than realtime; the planned fallback to 24fps and 1600×900 is unnecessary.

## Gotchas that cost real time

- **`setuptools<81` is load-bearing.** Chatterbox's watermarker imports `pkg_resources`, swallows the ImportError, and dies far away with `TypeError: 'NoneType' object is not callable`.
- **Release the MPS cache between scenes.** `narratr/device.py`. Without it the driver reservation grows to 14.6 GB against 2.9 GB live, the machine swaps ~1M pages per generation, and rtf goes from ~1.0 to 4-6. **Any stage running a model on MPS needs it.**
- **Name both streams when muxing.** Remotion writes a silent AAC track into every scene at a higher bitrate than the narration, so ffmpeg's default stream selection picks the silence. `-map 0:v:0 -map 1:a:0`. Verify with `volumedetect`, not by checking a stream exists.
- **Mermaid caps its own SVG.** An inline `max-width: <n>px` pins a diagram to a few hundred pixels in a 1920px frame. Only `!important` beats an inline style, and the container needs a definite box or `preserveAspectRatio` overflows instead of letterboxing.
- **Audio temp files must keep `.wav`.** torchaudio infers the container from the filename; a `.tmp` suffix fails with `Unsupported format: tmp`, and `format="wav"` does not override it.
- **`torchaudio::forced_align` has no MPS kernel.** The emission moves to CPU explicitly. **Do not set `PYTORCH_ENABLE_MPS_FALLBACK`** — it silently sends any unimplemented op to CPU and hides the cost.
- **Never hand-roll venv handling.** `uv run` plus `[project.scripts]` removes the class of bug.
- **Two scenes is not a benchmark.** The original rtf 1.59 came from two scenes — the two that run before memory pressure builds. It hid a 4× regression. Use six or more.

### ~~1. Fail loudly on silent audio~~ — done

`check_audible` in `narratr/stitch.py` measures every muxed segment and raises
`StitchError` below −80 dB. Verified against real ffmpeg: a generated silent file
reads −91.0 dB and is caught; a real segment reads −27.0 dB and passes.

### 2. `--only <scene-id>` for fast iteration

**Why:** tweaking one slide currently means a full pass over the spec. Content
addressing makes the other scenes cheap, but not free, and the feedback loop is
~2 minutes when it could be ~10 seconds. Short-clip iteration is the working
style, so this is worth more than it looks.

**How:** add `--only` (repeatable) to `narratr render` in `narratr/cli.py`.
Filter the scene list passed to each stage, and **skip stitching** when the flag
is present — a partial concat would overwrite `video.mp4` with an incomplete
video. Print a reminder that the full run is still needed for the final file.
Keep the manifest keyed on the whole spec so a later full run reuses the work.

### 3. Shiki highlighting for code scenes

**Why:** `render/remotion/src/Code.tsx` renders plain monospace. Code is hard to
read without highlighting, and the plan called for Shiki.

**How:** highlight on the Python side inside `render._props_for`, shelling out to
a small node script, and pass HTML through as a prop. That keeps the renderer
synchronous — doing it in the component would need `delayRender`. Pick a theme
that sits on the dark ground in `render/remotion/src/theme.ts`.

### 4. Chapter markers

**Why:** any video past a few minutes needs them.

**How:** in `narratr/stitch.py` after the concat. `probe_duration` already
measures each muxed segment, so cumulative offsets are in hand. Write an ffmpeg
metadata file with `[CHAPTER]` blocks and apply with
`-i chapters.txt -map_metadata 1 -c copy`. Scene headings make natural titles.
