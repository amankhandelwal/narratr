## BLUF

narratr turns a document into a narrated video. It is a **Claude skill plus a local CLI**: Claude reads a doc and writes `scenes.json`, then a detached local process renders it.

**The pipeline works end to end.** A run produces `runs/<id>/video.mp4` plus `captions.srt`.

Read [../research-plan.md](../research-plan.md) for the reasoning. This file carries state and next moves.

## Gotchas that cost real time

- **`setuptools<81` is load-bearing.** Chatterbox's watermarker imports `pkg_resources`, swallows the ImportError, and dies far away with `TypeError: 'NoneType' object is not callable`. Never "tidy" the pin.
- **The MPS cache release in `narrate.py` is not optional.** Without `torch.mps.empty_cache()` per scene, the driver reservation grows to 14.6 GB against 2.9 GB live, the machine swaps ~1M pages per generation, and rtf goes from ~1.0 to 4-6. Two tests guard it. **Any new stage that runs a model on MPS needs the same treatment.**
- **Atomic writes for audio must keep the `.wav` extension.** torchaudio infers the container from the filename, so a `.tmp` suffix fails with `Unsupported format: tmp`. Passing `format="wav"` does not fix it — the soundfile backend still reads the path.
- **Mermaid caps its own SVG.** It stamps an inline `max-width: <n>px` on the root element, which pins a diagram to a few hundred pixels in a 1920px frame. Only `!important` beats an inline style, and the container needs a definite box or `preserveAspectRatio` lets it overflow instead of letterboxing. Both are handled in `Diagram.tsx`; check rendered frames, not just that the render succeeded.
- **Never hand-roll venv handling.** An earlier `bin/narratr` re-exec'd into `.venv/bin/python` by comparing resolved paths; that is a symlink to the same pyenv binary, so the check always passed and the CLI silently ran on system `sys.path`. `uv run` plus `[project.scripts]` removes the class.
- **Two scenes is not a benchmark.** The original rtf 1.59 was measured on two scenes — the two that run before memory pressure builds. It hid a 4x regression. Benchmark six or more.

Then concatenate and listen straight through:
```sh
RUN=runs/<id>
uv run python -c "
import json; from pathlib import Path
spec=json.load(open('examples/research-plan.scenes.json'))
man=json.load(open(f'$RUN/manifest.json'))
Path('$RUN/concat.txt').write_text('\n'.join(
  f\"file '{Path('audio')/man['scenes'][s['id']]['audio']}'\" for s in spec['scenes'])+'\n')"
ffmpeg -y -f concat -safe 0 -i $RUN/concat.txt -c copy $RUN/full.wav
```

### ~~2. Alignment~~ — done

`narratr/align.py`. Forced alignment via torchaudio's MMS_FA bundle, **not**
WhisperX: the text is known exactly, so transcription was never needed and the
dependency was avoidable. Measured at rtf 0.03 — effectively free. Median word
score 0.999 over 241 words; `captions.srt` round-trips through ffmpeg.

`torchaudio::forced_align` has no MPS kernel. The emission is moved to CPU
explicitly for that one call. **Do not set `PYTORCH_ENABLE_MPS_FALLBACK`** to
"fix" a missing kernel — it silently sends any unimplemented op to the CPU and
hides the cost. Place the op deliberately instead.
