# Checkpoint — 2026-09-06

**For:** whoever picks this up after the audit branch.

---

## BLUF

An audit of the whole repo found **three critical defects, seven high and
sixteen medium**. All are fixed on `audit-1`, in eleven commits. A cold run
was verified end to end afterwards: 82s video, 7 chapters, 33 cues, A/V drift
0.33 ms.

The headline: **the coverage gate — the invariant the whole design rests on —
could be silently defeated**, and editing a spec crashed the run.

Read [2026-09-05-handoff.md](2026-09-05-handoff.md) for everything that came
before. That file's decisions all still stand.

---

## What was actually broken

**The coverage gate was defeatable.** `_slug` truncates a heading to 28
characters and the block counter resets at every heading, so two sections
sharing a slug produced identical ids — `## Notes` twice, or two long headings
differing only past the truncation. The gate compares *sets*, so a whole
section could go unmapped while `narratr validate` reported full coverage.

Mechanical extraction exists precisely to stop the author choosing the block
list. This meant the mechanical list itself under-counted, so following
`SKILL.md` exactly still passed a gate that should have failed.

**`test_ids_are_unique` passed because the one document it reads happens not to
collide.** 75 blocks, 75 unique. It asserted a sample, not a property — the same
shape as the silent-video bug: *"the claim needed was 'contains audio'; what I
measured was 'has an audio stream'."*

**Deleting a scene from scenes.json crashed the pipeline.** `refresh` never
pruned manifest entries for removed scenes, and `pending()` reads the manifest
rather than the spec, so the scene stayed queued and every stage died on a bare
`KeyError` that `cli.main` did not catch. Editing a spec and re-running is the
core workflow.

**Numbers vanished from the captions.** MMS_FA's vocabulary is lowercase latin
plus apostrophe, so `normalise` reduced every numeral to nothing and dropped the
token from the alignment target — while Chatterbox went on saying it. The
neighbouring words absorbed that audio and their timings skewed. The bundled
examples contain no digits, which is why it never showed.

## The pattern, again

Every hard bug in this repo's history has one shape: **a check that passes
because it measures the wrong property.** The audit found instances five and six.

| Where | What passed | What was true |
|---|---|---|
| `0dc8881` | "has an audio stream" | the stream was silence at −91 dB |
| `2892836` | per-scene durations fine | cumulative drift 229 ms by scene six |
| `f23d9c2` | coverage gate green | the author chose the block list |
| palette / flags / npm | "nothing to do" | cached video held the old frames |
| **`test_ids_are_unique`** | **these 75 did not collide** | **ids are not unique** |
| **`RENDERER_SOURCES`** | **the files someone remembered** | **not everything that draws a frame** |

`icons.py` and `highlight.mjs` were both created *after* the rule that says a
file which changes a pixel belongs in `RENDERER_SOURCES` — and `icons.py` was
created in the very commit that applied that rule to `package.json`. Vigilance
was not enough; both are in the key now, along with `package-lock.json`.

`ALIGNER_SOURCES` is the same idea one stage over: `align.py` and `spoken.py`
decide where every word lands, so `aligned` has its own key. Changing
alignment no longer re-narrates.

## What changed, by area

| Area | Change |
|---|---|
| **Coverage** | `_claim` breaks id collisions against the emitted set; duplicate scene ids and duplicate block ids rejected; scene types must carry what they render |
| **State** | manifest prunes removed scenes; `audio_key` hashes the clip's contents not its path; `align_key` added; `atomic_write` uses `mkstemp` |
| **Captions** | numerals spelled out via `narratr/spoken.py`; offset no longer skipped for an unaligned scene; only `stitch` writes captions; word score is the word's, not its first letter's |
| **Media** | `media.py` and `chapters.py` split out of `stitch.py`, dissolving the `stitch`↔`intro` cycle; 30-min timeout on every subprocess; FFMETADATA and concat-list escaping; `--no-install` on every `npx` |
| **CLI** | `pipeline.py` owns the stage list; `--only` produces a *playable* scene; `--run-name` sanitised; `PipelineError` base class; `narratr gc` |
| **Renderer** | dead edge selector removed; underscored node ids no longer mis-split; edge captions fade with their edge; unsafe ids rejected; `useMemo` that rebuilt every frame removed |
| **Schema** | `revealSteps` charset-constrained; length and count caps throughout; `voice.seed` bounded |
| **Tooling** | CI added; pre-commit runs four hooks not one; `make test` runs `tsc` and vitest; `setup_env.sh` installs the Node deps |
| **Docs** | `CONTRACT.md` describes the real payload; README's resume claim corrected; `presentation.md`'s 65-line bold blob fixed |

**Tests: 125 → 217 Python, 0 → 18 TypeScript.** The renderer had no test runner
at all; `tsc --noEmit` has always taken under a second and had never been run.

## Fixed but worth knowing

- **`voice.seed` never reached the model.** It was in the schema, the docs and
  `audio_key`, so it moved the cache without moving the output. Narration is
  reproducible now. Seeded per scene, so a resumed run gives a scene the same
  voice a cold one would.
- **`doctor` checked ffmpeg and node.** Not `ffprobe` (a separate binary both
  `stitch` and `intro` need), not `npx`, not `node_modules`, not the icon pack.
  A fresh clone got a green "Ready", spent the whole narration stage, and only
  then learned the renderer was never installed. Thirteen checks now.
- **`--only` printed a path that had not existed since artifacts moved to
  `store/`** — and the file it meant carried Remotion's silent track, so it
  could not be listened to. Against a working agreement that says look at the
  artifact.

## Still open

1. **Cue reveals to speech.** Unchanged and still pending #1 — see the previous
   checkpoint, which specifies it properly. The audit re-derived it
   independently and added nothing. One suggestion: build `narratr sync` *first*,
   so drift is measurable before it is changed. This repo's own record shows
   aggregate checks hiding accumulating error twice.
2. **Run a long document.** Still untested past 51 blocks, and
   `docs/research-plan.md` is now 75.
3. **Edge captions.** They now fade with their edge, but every fixture has empty
   edge labels, so that path is untested against a labelled diagram.
4. **No lock on a run directory.** Two `render` invocations against one run will
   clobber each other's `mark()` calls, and `--detach` makes double-launch easy.
5. **Stages do not overlap.** Narration is MPS-bound and rendering is
   Chrome-bound; pipelining them would cut ~26% off a cold run. Gate it on free
   memory — memory pressure is what caused the rtf 1.0 → 4-6 regression.
6. **Remotion is re-bundled per scene.** ~1.7s of fixed cost × N scenes.
